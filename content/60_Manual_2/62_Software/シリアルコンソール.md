## 接続

```bash
ls -l /dev/tty
ls -l /dev/ttyUSB*
```

これでそれっぽいのを見つける。 `ttyACM0`とか

接続にあたって、設定をする。接続する端末ごとに最適な設定があるのでそれを参照する。分からなければ下記の設定でとりあえずやってみる。

```bash
minicom -s
```

ボーレート(データを一秒でどのぐらい送るか) : 9600bps
パリティ : 8
ストップビット : 1

```bash
minicom -D /dev/ttyACM0
```
