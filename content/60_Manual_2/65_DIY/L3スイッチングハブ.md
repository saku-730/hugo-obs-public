## HP 2920 48G

### 初期設定

接続：micro usb

コンソールの入り方。

```bash
sudo screen /dev/ttyACM0 9600
```

コンソールの出方
Ctrl+a → k → y

物理初期化
1. Reset と Clear を同時に押す
2. Reset だけ離す
3. Clear は押し続ける
4. Test LEDが点滅し始めたら Clear を離す

初期化後、とりあえず`help`

`boot`
